# 修論の方向性をもう一回考える
## VRChatのワールドとして実装する
理由
- インタラクションの設計工数の削減
- 一つのワールドを作るだけで制作が完了する
  - デスクトップとVRで分けて実装する必要が無い(多少動作を考慮する必要はあるけれど、基本的に両者同じものを体験出来る)
- リファレンスが豊富
  - VRChatのワールド数は約10万
  - VR系のインタラクションの種類・アイデアが多い
- デバッグがアプリとしてビルドする方法よりも容易

## どんなコンテンツにするか？(企画)
### 「なぜ少数の長州軍が大軍に勝てたのか？を「武器」と「戦術」の視点から学ぶ。」
ターゲット： 論理的思考、因果関係の学習  
扱う範囲: 「石州口の戦い」の特定の一局面のみ  
プレイヤーの役割: 大村益次郎の副官・戦場の兵士  
#### VR体験:  
- 目の前に広がる**「作戦地図（ジオラマ）」から、実際の「戦場（1:1スケール）」**を体験することで、戦場全体の俯瞰視点と兵士視点どちらも得る。  
- 「ミニエー銃」と「火縄銃」を実際に手に取り、射程の違いを撃って体験する場面を用意。  
  - (射程に入った時に発泡して敵を倒す。敵も打ち返して来るけれど、弾がこっちに届かない描写によって、扱う武器の性能差を表現する。)
#### VN要素:  
- 大村益次郎が「なぜここで待ち伏せするのか」「なぜこの武器が有効か」を解説する。  
- 自分自信が歴史上の人物と会話したり、兵士となって戦闘したりする体験による没入。  
#### 教育的有効性:  
- テキスト（教科書）では伝わりにくい「射程距離の差」や「地形の有利不利」を、空間体験として直感的に理解できたかを検証できる。  
- 第二次長州征討で、何故長州藩が幕府軍に勝利することが出来たのかを、地理的要因・武器性能の側面から説明出来るようになる。  
#### 開発工数:
- マップは「作戦室」と「汎用的な山道」の2つで済むため、アセット制御がしやすい。

## どう実装するか？(技術)
### ワールド(体験)の構成について
主に3フェーズに分ける。  
- フェーズ1：説明フェーズ
  - 第二次長州征討とはどのようなものだったのか？
  - この体験において、ユーザーがどんな立ち位置で戦闘を体験するか？
  - を説明する。
  - 場所(背景)：電脳空間
- フェーズ2：コンテンツフェーズ
  - 大村益次郎の副官として、戦術と武器の説明を受けながら、ジオラマを見ることで戦場の俯瞰視点を得る
  - 兵士として銃を撃って敵との戦いを経験し、地理的優位性、武器の性能差を実感する
  - 場所(背景)：作戦司令室・戦場
- フェーズ3：まとめフェーズ
  - 貴方が体験したのはこの戦い全体の一部分です。他の戦いや、そもそも何故長州藩は幕府と戦うことになったのか？を自分でも調べてみてください。
  - 的な締めをする
  - 場所(背景)：電脳空間

体験の始まりと終わりを電脳空間にすることで、主に体験してほしいコンテンツ部分をより強調させる。
### モデリングについて
必要なモデル
- 作戦司令室
- 戦場のジオラマ
- 戦場
- 人物モデル
  - アニメーションも含む

人物モデルを自分で一から作ってコンテンツも作ってとやるのは不可能  
AIを使ったら簡略化することが出来るかもしれない  
現在アニメーション等でAIの活用は出来そう  
アセットを活用するにも、有料だったりぴったりのものが無かったりするので、自分で3Dモデリングを習得する必要がある。  
3Dモデリングとエフェクトの作成が出来る、「houdini」というツールを習得する。  

### システムについて
U#(C#をVRChat用に最適化された言語)を用いて実装していく。  
詳細は各フェーズの要件・設計の解像度をもっと上げてからだが、使用出来るアセット・ツールはbooth上に多く存在しているので、色々試しながら実装していく。  

## 実装計画
### 「一旦とにかくコンテンツを作り込むことに集中する」
3Dモデリングのスキルの習得、システムの設計・実装、空間設計等、ちゃんとしたクオリティのコンテンツの制作までに必要な工数が多い。  
スキルの習得も含めると、ICCE-TW2026の2月までには間に合わない。  
中間発表は、卒論段階で課題だったコンテンツのクオリティの改善・作り込みに注力している。を進捗として発表する。  
GCCE2026以降のものに出す方針とし、4-5月頃までコンテンツの作り込みに集中する。  
- 1月まで
  - システム全体のプロトタイプの作成
  - 3Dモデリング・エフェクトデザインの習得
- 2月
  - 中間発表
  - モデルのアセットや作成した3Dモデルを少しづつ導入し始める
- 3月-4月
  - PDCAサイクルを回して完成度を上げる
  - 実験を行う
- 5月以降
  - 論文執筆
