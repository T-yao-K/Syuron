## 採用した実装方針（会話で確定）

### 鏡（obj3）＝ VRC Mirror ＋ 上半分マスク ＋ 同一アバター

v8 の推奨は RenderTexture＋固定モデル。展示までの時間と制作一本化のため、**v8 が認める代替**を採用する。

- ワールド：店先の **平らな一枚窓**（建物全体を鏡にしない）
- 同じ長方形に `VRC Mirror`（初期 **Disabled**）
- 同じ長方形のマスク Quad を 1cm 手前。**上 55% は不透明の黒**（顔を確実に消す）。境目の細いグラデは任意
- `obj3` Interact で Mirror を Enable
- 確認は ClientSim ではなく **VRChat 実機**（desktop と VR、同じアバター）

パリティの担保＝**全被験者（desktop / VR）が同じ Private アバターを着る**。実験者立会いで開始前に読込。書生素材の規約で **Public 化・アバターペデスタルは不可**。

展示では、来場者のアバターが映る。**自分が書生アバターを着て実演する**前提。ペデスタルで着替えさせない。

RenderTexture 方式は捨てていない。手順は `銀座実装セットアップ.md` §B の旧項。今は使わない。
