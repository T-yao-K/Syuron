# 銀座実装セットアップ — BeatSequencer 配線 ＆ 鏡（下半分）手順

> 対になるコード：`Assets/Scripts/BeatSequencer.cs` / `BeatInteract.cs` / `GlowHighlight.cs`（既存 `MessageWindow` / `NextButton` 流用）。
> ⚠️ UdonSharpはC#サブセット。編集後は必ず Unity で再コンパイル → ClientSim で desktop 再生確認（`AGENTS.md` 参照）。

---

## A. BeatSequencer の配線

### 1. オブジェクトを用意
- 空の GameObject「BeatSequencer」を作り `BeatSequencer.cs` を付ける。
- ボイス用 `AudioSource` を1つ（BeatSequencer と同じGOでよい）。
- 終了状態用に、暗転パネル＋「体験終了」テキストの GameObject「EndState」（最初は非アクティブでよい。Start で自動的に false にされる）。

### 2. 各インタラクト対象（5個）
- 牛鍋屋の暖簾 / ハイカラ若者・鉄道掲示 / 鏡 / 新聞売り・掲示 / ガス灯・暦。
- それぞれに **Collider**（VRChatのInteractに必要）と `BeatInteract.cs` を付け、`sequencer` に BeatSequencer を割り当てる。
- それぞれに `GlowHighlight.cs`（発光させたい Renderer を `targetRenderer` に。未指定なら自身）。

### 3. BeatSequencer のインスペクタ
- `messageWindow` ← 既存 MessageWindow
- `voiceSource` ← 上のAudioSource
- `opText` / `opVoice` ← OPの文言（`ウィンドウ文言_5obj版.md` のOP）とボイス
- **配列は同じ順番・同じ長さ（5）**で登録：
  - `glows[]` ← 各対象の GlowHighlight（obj1→obj5の順）
  - `interactables[]` ← 各対象の GameObject（同順）
  - `windowTexts[]` ← 各obj の窓文言（`ウィンドウ文言_5obj版.md` から）
  - `voices[]` ← 各obj のボイス（無ければ空のまま＝グレーボックスは noVoiceGuardSeconds 後に進める）
- `endState` ← EndState

### 4. 「次へ」トリガー（NextButton の付け替え）
- 既存 `NextButton.cs` は `gameManager.SendCustomEvent("GoToNextPhase")` を呼んでいる。これを **`"TryAdvance"`** に変更し、参照に BeatSequencer を割り当てる（1行修正）。
- もしくは NextButton 相当を新規に作り、Interact で `sequencer.TryAdvance()` を呼ぶ。
- ボイス終了まで `TryAdvance` は無効（`canAdvance` ガード）＝内容スキップ防止。

### 5. 動作（ClientSim/desktop で確認）
発光 → 対象をクリック → 窓に文言＋ボイス → ボイス終了まで「次へ」無効 → 「次へ」で次が発光 → 5個使い切ると EndState（暗転・体験終了）。

## B. 鏡（obj3）— 下半分のみ可視の RenderTexture 手順

狙い：**顔・頭は暗転、腰から下だけが映る**（袴・刀のない腰・革靴）。プレイヤーの実アバターに依存させず、**ポーズ固定モデルを鏡像として撮る**ことで desktop/VR 同一像＝パリティを堅くする（実装設計v8 §2推奨）。

> ⚠️ VRChat標準の `VRC Mirror` は「プレイヤー自身のアバター」を映すので、今回の用途には**使わない**（実アバター反射方式を採る場合のみ）。

### 手順
1. **ポーズ固定モデルを用意・配置**
   - 和装ベース（VRoid/既製/無料）。腰から下が"それっぽい"だけでよい（袴・空の腰・革靴）。
   - 鏡の「向こう側」に、鏡面に対して対称（左右反転して見える位置）に置く。体験は鏡の前で立ち止まる設計なので、**固定配置**でよい。
2. **専用レイヤー**
   - レイヤー `MirrorOnly` を作り、ポーズ固定モデルをそのレイヤーに。
   - シーンのメイン描画（プレイヤーが直接見る側）からは見えないよう、必要なら配置・カリングで隠す。
3. **Mirror Camera**
   - カメラを新規作成。鏡面の位置から、ポーズ固定モデルを撮る向きに。
   - Culling Mask ＝ `MirrorOnly`（＋必要な背景のみ）。
   - 新規 **RenderTexture**（512〜1024で十分）を作り、カメラの Target Texture に割り当て。
   - 左右反転が必要なら、カメラ側のスケール反転か、貼り先マテリアルのUV反転で対応。
4. **鏡面（Quad）に映す**
   - 鏡の位置に Quad を置き、`Unlit/Texture` 等のマテリアルに上記 RenderTexture を割り当て。これが「硝子に映る自分」。
5. **下半分のみ可視・上半分暗転**（手早い順）
   - 方法A（推奨・最速）：Quad の**上半分に黒い不透明パネルを重ねる**。グレーボックスはこれで十分。
   - 方法B：マテリアル/シェーダで UV.y < 0.5 のみ表示、上は黒。
   - 方法C：映すモデル自体、腰から上を作らない・隠す。
6. **腰に手の演出**（obj3使用時）
   - ポーズ固定モデルの Animator に「腰に手をやる」トリガー、または一人称の手を視界に出す。グレーボックスでは省略可。
7. **パリティ確認**
   - ClientSim(desktop) と HMD の両方で、鏡像（下半分のみ）が**同一**に見えること。RenderTexture方式はアバター非依存なので原理上同一像。

### 注意
- RenderTexture＋カメラは描画コストが乗る。**鏡カメラは常時稼働させず、obj3接近時のみ有効化**するとよい（BeatSequencer の EnterBeat で対象がobj3の時にカメラをON、など）。
- 解像度は控えめに。PC前提（Questは鏡が重い）。
- 反射の厳密さより「立ち止まって下半身が映る」体験が成立すればよい（暗がりがアイデンティティ喪失を強める設計）。
