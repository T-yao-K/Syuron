# 銀座実装セットアップ — BeatSequencer 配線 ＆ 鏡（下半分）手順

> 対になるコード：`BeatSequencer` / `BeatInteract` / `GlowHighlight` / `NextButton` / `BackButton` / `MessageWindow` / `MessageWindowPageZone`。
> 進捗の入口：`作業状況_展示前.md`。
> ⚠️ UdonSharpはC#サブセット。編集後は Unity 再コンパイル → ClientSim desktop。鏡の本確認は VRChat 実機。

---

## A. BeatSequencer の配線

### 1. オブジェクトを用意
- 空の GameObject「BeatSequencer」を作り `BeatSequencer.cs` を付ける。
- NextButton / BackButton 用の Interact オブジェクトを各1つ（`BackButton.cs` は新規追加）。

### 2. 各インタラクト対象（5個）
- 牛鍋屋の暖簾 / ハイカラ若者・鉄道掲示 / 鏡 / 新聞売り・掲示 / ガス灯・暦。
- それぞれに **Collider**（VRChatのInteractに必要）と `BeatInteract.cs` を付け、`sequencer` に BeatSequencer を割り当てる。
- **同一オブジェクトの `GlowHighlight` を `Glow Highlight` に割り当て**（未設定なら `Start` で自動取得を試行）。ビート番号は `BeatSequencer` の `glowObj1`〜`glowObj5` と照合して解決される。
- （任意フォールバック）`beatIndex` を 0〜4（obj1→obj5）で設定。
- それぞれに `GlowHighlight.cs`（発光させたい Renderer を `targetRenderer` に。未指定なら自身）。

### 3. BeatSequencer のインスペクタ
- `messageWindow` ← 既存 MessageWindow
- **ページ配列**（1要素＝窓1ページ。`ウィンドウ文言_5obj版.md` の行単位で分割）：
  - `opPages[]` ← OP（3行）
  - `obj1Pages[]` … `obj5Pages[]` ← 各ビート
  - `edPages[]` ← ED（2行）
- **終了案内**（ED 最終ページで「次へ」を押したあとに解放）：
  - `endPagesDesktop[]` / `endPagesVR[]`（推奨・1行＝1ページ）
  - 未設定時は `endTextDesktop` / `endTextVR` を改行 `\n` で分割
- `glowObj1` … `glowObj5` ← 各 obj の Cube 上の `GlowHighlight`（obj1→obj5）
- `enableDesktopKeys` ← ON で desktop のみ **E=次へ / Q=戻る**（ワールド固定ボタン不要）
- レガシー：`windowTexts[]` / `opText` / `edText` はページ配列未設定時の1ページフォールバック

### 3b. MessageWindow の UI 追加（任意だが推奨）

MessageWindow プレハブの Canvas 内に小さめの TMP を2つ追加し、Inspector で割り当てる。

| フィールド | 用途 | 配置例 |
|---|---|---|
| **Page Indicator Text** | `3 / 12` 形式のページ番号 | 窓の右下 |
| **Desktop Hint Text** | `E: 次へ  Q: 戻る`（VR では自動非表示） | 窓の左下 |

### 4. ページ操作（desktop 優先）

| 手段 | 動作 |
|---|---|
| **E キー**（desktop） | `TryPageNext()` |
| **Q キー**（desktop） | `TryPageBack()` |
| NextButton / BackButton（任意） | ワールド固定の Interact 代替。なくても desktop は E/Q で可 |

> **VR**：ウィンドウ内に Next/Back ボタンを置く案はパイロット前タスク（`Docs/TODO.md` 参照）。現状は NextButton/BackButton か今後実装する窓内 UI。

### 5. 動作（ClientSim/desktop で確認）
1. OP ページが表示 → **E / Q** または Next/Back でページング。**ページ番号**（例 `3 / 18`）が表示される
2. OP **最終ページ到達** → obj1 が発光
3. 発光対象を Interact → そのビートのページが末尾に追加され先頭へジャンプ
4. そのビート **最終ページ到達** → 次オブジェクトが発光（5個目後は ED ページ）
5. ED **最終ページで「次へ」** → 終了案内ページが追加される（**自動ジャンプしない**）
6. 終了案内も **E/Q でページング・戻れる**（OP まで遡れる）
7. **使用済み**オブジェクトを Interact → 新規追加なし・該当ビート先頭ページへジャンプのみ

## B. 鏡（obj3）— 現行：VRC Mirror ＋ 上半分マスク

狙い：**顔・頭は暗転、腰から下だけが映る**（袴・刀のない腰・革靴）。  
2026-09 採用：実アバターを `VRC Mirror` で映し、**同一 Private アバター**で desktop/VR を揃える（実装設計 v8 §2 の代替）。RenderTexture 方式は下の §B2。

> 建物全体を鏡にしない。店先の **平らな一枚窓** だけ。

### 前提（アバター）

- 視点アバター（VRoid 書生風）を VRChat に **Private** で上げ、体験前に着せる。
- 書生素材規約：Public 化・ペデスタル不可。ワールドにペデスタルを置かない。
- 展示は自分がそのアバターで実演する。来場者のアバターが映ると物語は崩れる。

### 手順

1. **窓**  
   `obj3_Mirror` 付近の壁に、縦長 Quad（窓）。既存メッシュに無理に合わせない。
2. **VRC Mirror**  
   窓と **同じ位置・回転・スケール**。初期 **Disabled**。解像度は控えめ（PC 前提）。
3. **マスク Quad**  
   Mirror の 1cm 手前に、同じ長方形。  
   - 上 55%：不透明の黒（顔を消す）  
   - 境目 5〜10%：任意でグラデ  
   - 下：完全透明  
   Unlit＋アルファテクスチャでよい。上半分を別の黒 Quad で覆うだけでも MVP。
4. **Interact で ON**  
   obj3 の `BeatInteract` 成功時に Mirror の GameObject を Enable。マスクは常時出してよい（OFF 中は暗い硝子）。
5. **立ち位置**  
   窓の前で止まる導線のまま。同じアバターなら腰の映る位置はほぼ固定。
6. **確認**  
   ClientSim の鏡は当てにしない。VRChat で desktop と VR、同じアバター。「顔が出ない／袴・空の腰・革靴」。

### 腰に手

専用 Animator は必須ではない。実アバターなら、鏡の前で手を腰にやる／窓テキストに任せる。展示では省略可。

## B2. 代替：RenderTexture ＋ 固定モデル（いまは使わない）

v8 推奨。アバター非依存でパリティが堅い。時間があれば展示後に戻せる。

1. 袴・空の腰・革靴の固定モデルを鏡の向こうに置く。レイヤー `MirrorOnly`。
2. Camera の Culling Mask＝`MirrorOnly`。Target Texture＝RenderTexture（512〜1024）。
3. 鏡面 Quad にそのテクスチャ。上半分を黒で覆う。
4. カメラは obj3 ビート中のみ Enable。
